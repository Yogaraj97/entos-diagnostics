🎯 WHAT YOU GET
═══════════════════════════════════════════════════════════════════════════════

5 HUMAN-READABLE DIAGNOSTICS:

1. Loaded Applications
   └─ Table: App ID | Instance ID | State | PID
   └─ Shows running app instances

2. Installed Applications
   └─ Table: App ID | Name | Version | Category
   └─ Shows installed packages

3. Package Manager
   └─ Cache status + Table: Name | Version | Size | Type | Installed
   └─ Shows package database

4. Resource Statistics
   └─ Total CPU/Memory + Table: App ID | CPU% | Memory MB | Timestamp
   └─ Shows resource usage

5. Window Manager
   └─ Focused app + Table: App ID | Z-Order | Focused | Visible
   └─ Shows window hierarchy

ALL OUTPUT: Human-readable table format (NO JSON to users)


🏗️ ARCHITECTURE HIGHLIGHTS
═══════════════════════════════════════════════════════════════════════════════

UNIFIED PATTERN (Reusable):
  1. Manager-specific class (AppManagerDumpsys)
  2. Queries Thunder plugin via RpcClient
  3. Parses JSON response
  4. Delegates to UnifiedDiagnostics::format*()
  5. Returns human-readable table

EXTENSIBILITY:
  - Add WindowManagerDumpsys (reuse UnifiedDiagnostics)
  - Add PowerManagerDumpsys (reuse UnifiedDiagnostics)
  - Add PackageManagerDumpsys (reuse UnifiedDiagnostics)
  - Each new manager = ~100 lines of code

KEY CLASSES:
  ✅ TableBuilder (12 methods) - Render any table with alignment
  ✅ UnifiedDiagnostics (13 methods) - Format methods + helpers
  ✅ AppManagerDumpsys (9 methods) - Query Thunder + delegate
