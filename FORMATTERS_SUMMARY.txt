FORMATTER #1: formatRuntimeManager
================================================================================

Lines:        88-172 (85 lines)
Called From:  Snapshot.cpp:135
Called Via:   entos-diagnostics dumpsys --section runtime
Input Check:  section["data"].isMember("apps")

PURPOSE:
  Display all currently loaded applications with their instance IDs, state, and PID

INPUT JSON STRUCTURE:
  {
    "loaded_apps": [
      {
        "appId": "com.netflix.nrdp",
        "instanceId": "instance-001",
        "state": "running",
        "pid": 1234
      }
    ]
  }

FIELD VARIANTS SUPPORTED:
  - loaded_apps (primary) or apps (fallback)
  - appId (string)
  - instanceId (string)
  - state (string)
  - pid (integer → converted to string)

OUTPUT COLUMNS:
  | App | Instance ID | State | PID |

OUTPUT EXAMPLE:
  RUNTIME MANAGER:
  
      GUIAppManagerV2:
          App                  | Instance ID      | State                | PID
          -------------------- | ---------------- | -------------------- | --------------------
          com.netflix.nrdp     | instance-001     | running              | 1234
  
      Summary:
          Loaded Apps: 1

FALLBACK BEHAVIOR:
  - Missing appId: shows "--"
  - Missing instanceId: shows "--"
  - Missing state: shows "--"
  - Missing pid: shows "--"
  - No apps array: shows summary only

DATA EXTRACTION LOGIC:
  1. Check "loaded_apps" array
  2. If not found, check "apps" array
  3. For each array element:
     - Extract appId as "App" column
     - Extract instanceId as "Instance ID" column
     - Extract state as "State" column
     - Extract pid (convert int to string) as "PID" column
  4. Build table with padding (min 20 chars per column)
  5. Add summary line with total count

PERFORMANCE:
  O(n) where n = number of loaded apps
  Typical: < 100 apps
  Time: < 1ms for typical data

                        HOW TO HIT FORMATTERS

  entos-diagnostics dumpsys --section runtime

  entos-diagnostics dumpsys --section resource
  entos-diagnostics dumpsys --section window

Multiple Sections:
  entos-diagnostics dumpsys --section runtime --section package --section resource --section window

All Sections:
  entos-diagnostics dumpsys

From Code (C++):
  #include "entos/DumpsysFormatter.h"
  
  // Get data as Json::Value (from API or test data)
  Json::Value sectionData;
  
  // Call appropriate formatter
  std::string output = DumpsysFormatter::formatRuntimeManager(sectionData);
  std::cout << output;

Flow Through Code:
  1. CLI: entos-diagnostics dumpsys --section runtime
  2. main.cpp: parseCommandLine() extracts "runtime"
  3. DiagnosticsCollector: Fetches data from Thunder APIs
  4. Snapshot.cpp: textOutput() routes to formatRuntimeManager()
  5. DumpsysFormatter: Formats as table
  6. Console: Displays output
